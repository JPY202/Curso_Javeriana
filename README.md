# Curso de Métodos y Simulación Estadística

Cada unidad tiene su carpeta con los archivos fuente (`Unidad 1`, `Unidad 2`...). Las actividades evaluativas tienen su propia carpeta (`Actividad 1`...).

La carpeta `docs` contiene el sitio que publica GitHub Pages:

- `docs/index.html`: página inicial con la lista de unidades.
- `docs/unidad1/`: sitio de la Unidad 1, generado desde `Unidad 1`.
- `docs/actividad1/`: enunciado de la Actividad 1, generado desde `Actividad 1`.

Para agregar una unidad, cree su carpeta, ponga en su `_site.yml` la línea `output_dir: "../docs/unidad2"`, cree esa carpeta y agregue el enlace en `docs/index.html`.
